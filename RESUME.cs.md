## Description

WPF user control `CefBrowser` obalující CefSharp (Chromium Embedded Framework) prohlížeč a implementující `ISunamoBrowser`, pro vkládání webového obsahu do WPF appek. Použití je niche (appky, které potřebují vlastní embedded Chromium místo WebView2).
Balíček je self-contained: nereferencuje jiné Sunamo balíčky, rozhraní prohlížeče a delegáty má zkopírované jako internal.
