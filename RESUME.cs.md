## Description

WPF user control `CefBrowser` obalující CefSharp (Chromium Embedded Framework) prohlížeč pro vkládání webového obsahu do WPF appek. Vznikla migrací ze `sunamo.wpf` jako nový wnp balíček. Použití je niche (jen appky, co potřebují vlastní embedded Chromium místo WebView2).
